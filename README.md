# Boulevard Racer v15

The complete game is in `index.html`, including all images, music and sound effects.

## Upload through GitHub

1. Upload the contents of this folder to the root of your GitHub repository. Do not upload the ZIP itself.
2. For Netlify, import that repository. No build command is needed; the included `netlify.toml` publishes the repository root.
3. Alternatively, GitHub Pages can serve `index.html` from the repository root.
4. Share the resulting website URL and test Play on phone in Safari.

This is the v15 build with the classic Porsche-style rear-view mirror. Personal best scores are stored locally; a public leaderboard is not included.
